# TimeFragments - Zaman Kırıkları

![Game Banner](docs/banner.png)

## 🎮 Oyun Hakkında
Zamanı kontrol edebildiğin 3D mobil aksiyon-platform oyunu. Geri sarma mekaniğiyle bulmacaları çöz, düşmanlardan kaç ve seviyeleri tamamla.

## 🚀 Özellikler
- ⏳ Zaman geri sarma mekaniği
- 🎮 30+ prosedürel oluşturulan seviye
- 👹 4 farklı düşman tipi
- 💎 Yetenek ağacı ve gelişim sistemi
- 🏆 Global liderlik tablosu
- 🎵 Uyarlanabilir müzik sistemi

## 🛠️ Teknolojiler
- Godot 4.2.1
- C++ GDExtension
- Google Play Services
- AdMob
