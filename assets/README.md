# Assets Klasörü

Bu klasör oyun varlıklarını içerir:

## 📁 models/
- `player/` - Oyuncu karakteri modelleri
- `platform/` - Platform modelleri
- `enemy/` - Düşman modelleri
- `crystal/` - Kristal modelleri

## 📁 audio/
- `music/` - Arka plan müzikleri
- `sfx/` - Ses efektleri
- `ambient/` - Ortam sesleri

## 📁 textures/
- UI görselleri
- Texture dosyaları

## 📁 fonts/
- Oyun yazı tipleri

## Not
Gerçek assetler eklenecek. Şimdilik Godot primitive'leri kullanılıyor.
